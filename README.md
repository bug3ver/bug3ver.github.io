⚽ Torzähler SC Hardt
Ein Torzähler für den Jugendfußball (z. B. E-Jugend), den man auf dem Handy direkt am Spielfeldrand bedient. Er zählt die Tore von zwei Mannschaften, unterstützt bis zu 6 Spiele (Spielzeiten) und kann auf einem oder zwei Spielfeldern gleichzeitig genutzt werden. Dazu gibt es einen Timer, ein Wappen und Effekte bei Toren.

Funktionen im Überblick
Spielfelder
Anzahl Felder: 1 oder 2 Spielfelder gleichzeitig. Jedes Spielfeld hat eigene Mannschaftsnamen und einen eigenen Spielstand.
Die Spielfelder sind farblich getrennt: Spielfeld 1 grün, Spielfeld 2 blau.
Die Ergebnis-Boxen darunter haben dieselbe Farbe wie ihr Spielfeld.
Spiele (Spielzeiten)
Anzahl Spiele: 1 bis 6 Spiele pro Spielfeld einstellbar.
Aktuelles Spiel: Hier wählst du, in welches Spiel gerade Tore eingetragen werden. Das gilt für beide Spielfelder gemeinsam.
Man kann das aktuelle Spiel auch wählen, indem man in der Ergebnis-Tabelle auf die Zeile des Spiels tippt.
Wird die Anzahl der Spiele verkleinert, springt das aktuelle Spiel bei Bedarf auf das letzte vorhandene Spiel.
Neu gestartet oder zurückgesetzt beginnt die App immer mit Spiel 1.
